
# My Budget Tracker

A simple static Budget Tracker website built using HTML, CSS, and JavaScript.

## Project Description

The Budget Tracker helps users view their income, expenses, balance, and recent transactions.

## Project Files

- index.html - Website structure.
- style.css - Website styling and design.
- script.js - JavaScript starter code.

## Features

- Dashboard section.
- Total income display.
- Total expenses display.
- Balance display.
- Recent transactions table.
- Responsive layout.

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open index.html in a web browser.

This is the static skeleton version of the Budget Tracker.
